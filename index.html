pcieshark

Open toolkit for PCIe trace, enumeration, and analysis. One stack for real endpoints and emulated fabrics.

View on GitHub Sample analysis report

What it does

Inspect and validate PCIe traffic on real endpoints and emulated fabrics. A portable C library and command-line tools sit under a desktop analyzer for live capture and offline review — open, inspectable, and independent of a vendor stack.

TLP create and parse

Build, decode, and filter configuration, memory, and completion packets.

Trace review

Open CSV, QEMU pci_cfg_* logs, or library captures. Match requests to completions.

Desktop analyzer

Packet table, payload decode, BDF lookup, search, match analysis, and HTML report export.

PCI backend

Read Linux sysfs config space on a live endpoint, or use the software dummy backend without hardware.

QEMU topologies

Shared golden AI fabric for Zephyr or Linux guests: root ports, switches, NVMe, GPU stand-ins, NICs.

Measured cfg/s

Emulator Measure times a real config-space walk of the deployed topology. No invented token rates.

Workflows

  1. Open a captured CSV, QEMU log, or .pcie file and inspect TLPs.
  2. Run the Zephyr or Linux QEMU topology and review config-space traffic live.
  3. Point the PCI backend at a real endpoint and check link capability data.
  4. Export an HTML analysis: type counts, match summary, devices at config 0x00.

Quick start

Linux, CMake 3.13+, a C compiler, and Python 3 for the desktop analyzer.

git clone git@github.com:khademullah/pcieshark.git
cd pcieshark
cmake -S . -B build
cmake --build build -j$(nproc)
./run_pcieshark.sh
